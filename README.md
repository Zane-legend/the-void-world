# the void world

Браузерная 2D action/fantasy/sci-fi игра о путешествии по островам Пустоты.

## Запуск
Откройте `index.html` в современном браузере. Игра не требует сборки, npm или внешних библиотек.

## Управление
- **WASD** — движение
- **ЛКМ** — атака
- **Z** — рывок
- **E** — инвентарь
- **Esc** — пауза / закрыть окно
- **ПКМ** — открыть магазин рядом с торговцем; в инвентаре ПКМ по экипированному предмету снимает его
- **Space** — зарезервирована под прыжок (в этой демо-версии прыжок визуально не реализован)

## Цель
Побеждайте врагов, получайте опыт и монеты, покупайте экипировку и победите Осколочного паладина.

## Публикация через GitHub Pages
1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После завершения публикации сайт будет доступен по адресу:
   https://Zane-legend.github.io/the-void-world/

## Примечание
Это самостоятельный игровой прототип на HTML, CSS и JavaScript с 2D-перспективой, а не полноценная 3D-игра. Некоторые механики упрощены для демо.
